B CAPITAL GROUP — SITO AGGIORNATO / TREASURY DIRETTA
======================================================

ISTRUZIONI RAPIDE PER GITHUB PAGES
1. Estrai questo ZIP.
2. Apri la cartella B-Capital-Group-Sito.
3. Carica TUTTI i file e la cartella assets/ nella ROOT del repository GitHub Pages.
4. Sostituisci i file presenti, senza creare una seconda cartella.
5. Apri il sito; scegli dal menu Patrimonio gestito.

NON SERVE CLOUDFLARE / WORKER / CHIAVI API
- treasury-config.js include 5 indirizzi PUBBLICI Injective.
- treasury-live.js interroga direttamente dal browser le API pubbliche Injective LCD e CoinGecko.
- Se CoinGecko non funziona, prova automaticamente DefiLlama.
- Mostra patrimonio INJ complessivo, staking, reward, INJ/USD e P/L di mercato 24h.
- I dati vengono aggiornati ogni 30 secondi quando il sito è aperto e visibile.
- Se la connessione o l'API non funziona, vengono mostrati dati non disponibili o marcati come non aggiornati.

PRIVACY: IMPORTANTE
QUESTO SITO È PUBBLICO. Chiunque può leggere i cinque indirizzi in treasury-config.js
usando gli strumenti per sviluppatori, anche se la pagina non li mostra.
Non includere mai seed, chiavi private, passphrase, token segreti o password.
Per NASCONDERE gli indirizzi al pubblico serve una componente server (ad esempio Worker).

SIGNIFICATO P/L 24H
P/L stimato = INJ totali ATTUALI × (prezzo INJ attuale - prezzo INJ stimato 24h fa).
NON è il profitto effettivo delle posizioni: non considera movimenti,
depositi, prelievi o acquisti/vendite. L'AUM indicato comprende esclusivamente
INJ disponibili, INJ in staking, INJ in unbonding e reward non riscossi.

PRECISIONE E DISPONIBILITÀ
- Gli aggiornamenti dipendono dalla raggiungibilità delle API pubbliche,
  dalla loro policy CORS e da eventuali limiti di traffico.
- Da un sito statico non è possibile assicurare l'operatività 24/7.
- Il refresh si ferma se la scheda è nascosta e riprende quando ritorna visibile.
- Il sito non invia transazioni e non offre funzioni di firma dei wallet.

ALTRI FILE
- index.html: pagina principale
- style.css: grafica desktop/mobile
- script.js: menu/lingue/animazioni
- treasury-config.js: elenco wallet pubblici
- treasury-live.js: lettura blockchain + prezzo
- assets/: logo, favicon e foto CEO fissa
